# Security policy

Harngine is pre-release software. Security fixes are applied to the current `main` branch; no older
release line is currently supported.

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/neucine/harngine/security/advisories/new). Do not
open a public issue for a suspected vulnerability.

Include the affected commit or version, a minimal reproduction, the expected and actual behavior,
and any relevant platform or dependency details. Remove credentials, model-provider tokens,
personal data, and proprietary source before attaching logs or fixtures.

We aim to acknowledge a report within seven days and will coordinate disclosure after the issue has
been assessed and a fix is available.
